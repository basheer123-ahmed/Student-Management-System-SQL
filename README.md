 $$ Student Management System (SQL)

** Description
A mini SQL project demonstrating database design and querying using MySQL.
The project manages students, courses, and enrollments.

** Tables
- STUDENT: Stores student details
- COURSE: Stores course and faculty details
- ENROLLMENT: Maps students to courses with marks

** Concepts Used
- CREATE DATABASE & TABLE
- PRIMARY KEY and FOREIGN KEY
- INSERT statements
- INNER JOIN (multiple tables)
- GROUP BY and HAVING
- Normalization (1NF, 2NF, 3NF concepts)

** Sample Query
Course-wise student count using GROUP BY and HAVING.
